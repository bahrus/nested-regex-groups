# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [Unreleased]

### Added
- Core parsing functionality with `nestedRegex()`, `createParser()`, `tryPatterns()`
- Template tag syntax with `rx`, `rxPattern`, and `rxParser`
- Support for dot notation in capture group names via groupMap
- Automatic conversion from dots to underscores in template tags
- Full TypeScript support with type inference
- Comprehensive test suite (43 tests)
- Documentation: README, GETTING_STARTED, TEMPLATE_TAG, PUBLISHING guides
- Examples for both core API and template tag usage
- Support for multiple nesting levels
- Pattern priority ordering
- Verbose error mode
- Zero dependencies

### Features
- ✨ Template tag syntax for clean, intuitive patterns
- 🎯 Multiple pattern matching with priority order
- 📦 Zero dependencies, tiny footprint
- 🔒 Type-safe with full TypeScript support
- 🚀 Fast with minimal overhead
- 🧩 Composable parsers
- 🌳 Tree-shakeable template tag module
